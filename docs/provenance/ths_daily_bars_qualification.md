# THS 日线来源与补丁边界

LakeEquity 的日线输入检查将 `ths` 纳入可识别的未复权价格来源。研究依赖中的对应集成补丁位于 `my_strategy/services/kronos_prediction.py`，其原冻结摘要与修改后摘要见 [本地补丁声明](local_patches.json)。本补丁不改变原生计算 wheel 或神经网络权重，也不代表上游已合并该修改。

来源标签只说明数据提供方，不能证明交易日终态。用于日线研究的数据必须是收盘后发布的完整日线；盘中抓取值应刷新并核查。需对相同股票、相同交易日和相同复权口径交叉检查 OHLC、成交量及单位，记录采集时间、数据代际、样本范围与差异。缺失或无法确认的值应保持不可用，不得用后来的价格替代历史已知值。

开发机的抽样明细、网络探测、补采日志、私有运行身份和本地数据不随公开包分发。历史抽样不能为未来采集自动背书；新安装与每次数据更新仍须独立检查来源、终态、覆盖及真实可得时间。
