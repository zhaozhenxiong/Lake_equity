# 一键流水线与默认方法

在研究概览点击“一键更新并生成今日结果”，系统依次执行预检、数据更新、覆盖判定、研究输入物化、默认方法维护、选股、回测和报告汇总。各阶段状态及阻断原因保存在 `var/pipeline/<pipeline_id>/`，并在任务与报告页面展示。

## 运行

```powershell
# 只读预检：不采集、不物化、不训练
.\.venv\Scripts\python.exe -B run.py pipeline --dry-run

# 更新并执行；需要合法数据源及已准备的默认策略发布
.\.venv\Scripts\python.exe -B run.py pipeline

# 重用已发布的数据代际
.\.venv\Scripts\python.exe -B run.py pipeline --skip-update
```

`--end YYYY-MM-DD` 指定目标日；省略时使用最近已收盘交易日。`--packs core|extended|full` 选择采集范围，其中 extended/full 当前均调用上游完整日更流程。`--no-scan`、`--no-backtest` 可跳过相应阶段。完整参数以 `pipeline --help` 为准。

## 覆盖与阻断

必需数据由 active 发布的 `data_contract` 决定。覆盖必须满足目标日要求，缺失时阻断后续研究；可选缺口逐项记录。来源和覆盖以本机实际发布数据为准，能力目录存在或采集命令退出成功不代表覆盖完整。

退出码：0 完成；3 更新、重拟合或回测等发生降级；4 必需数据或默认方法缺失；2 配置或预检错误；1 未预期失败或取消。`coverage.json`、`pipeline.json`、`report.json` 分别保存覆盖、阶段摘要和完整报告。

## 默认方法与模型归档

默认方法只解析 `GET /api/v1/strategy/active`。日常流程复用该发布；`--refit auto` 仅判断是否到期，`--refit now` 生成候选权重和发布，不自动激活。新安装没有默认方法、行情或权重，应先通过模型中心及研究流程建立可用发布。

模型中心的高级区保留训练、比较和历史研究入口。模型归档先预览再确认，保留模型产物和历史报告；读取历史模型时仍可解析归档位置。失败构建清理同样需要预览并确认，运行中的任务不应被清理。

## 来源与研究边界

THS 日线属于已纳入校验的原始价格来源，但研究前仍需核实是否为收盘后的最终日线；盘中快照不能冒充完整日线。来源标签本身不能证明终态、历史可得时间或研究资格。

Sharpe 使用日收益均值除以标准差再乘以 √252，默认无风险利率为零；少于 60 个交易日或零波动时返回空值和原因。缺少执行开盘导致零成交的回测会标记绩效不可用，不能将其解释为有效零收益。历史结果、PSR/DSR 和预测均不能证明未来收益。

上游日更任务目前没有统一的整体 deadline/checkpoint。本版本尚未完成全新联网安装及 Linux/macOS 安装验收。更多执行约束见 [执行规则](EXECUTION_RULES.md)。
