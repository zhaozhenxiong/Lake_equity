# Sharpe 导向的研究与验证

本文说明当前工具和后续研究方法；各项计划需独立验收。公开发行不附带开发机策略、训练权重、实验排名或收益记录。

## 已提供的工具

- 回测报告展示 Sharpe、最大回撤、费用、换手及可用的 PSR/DSR；样本不足时显示原因。
- 回测预检验证输入、股票池、日期和执行条件，正式任务使用冻结模型或明确的历史序列。
- 前瞻账本逐日冻结信号，再以之后发布的数据对账；没有样本时保持空状态。
- 默认发布与研究候选分开保存，生成候选不自动替换 active 发布。

前瞻账本命令：

```powershell
.\.venv\Scripts\python.exe -B run.py forward --help
.\.venv\Scripts\python.exe -B run.py forward record --help
.\.venv\Scripts\python.exe -B run.py forward verify --help
.\.venv\Scripts\python.exe -B run.py forward report
```

记账、验证和研究任务会写本机运行状态。运行前应核对数据覆盖、已选策略、时间截止和模型资产。

## 研究顺序

1. 固定数据代际、股票池、交易规则、成本与基线，预注册实验配置和选择规则。
2. 在开发段评估调仓频率、持仓缓冲、持仓数量及仓位约束，报告费用后的完整账本。
3. 对同一配置施加多档成本压力，检查结果对交易费用和换手的敏感度。
4. 新特征、模型或集成仅在有明确假设时引入；训练处理器只拟合训练段。
5. 留出段用于独立复核，不能反复据其结果调参；发布后的前瞻样本另行累计。

晋升标准应在实验前明确，包括成本后表现、回撤、样本量和稳定性。未通过标准的候选应如实保留失败结论，不通过改指标或反复挑选留出段制造改善。

## 当前边界

当前成分股、复权、公司行为、来源终态和因子真实可得时间需要逐项核验。PSR/DSR 对输入样本和统计假设敏感；它们不替代时间隔离、数据来源审计或真实执行验证。界面截图只展示已有开发环境的状态，不能作为新安装的覆盖或收益凭证。
