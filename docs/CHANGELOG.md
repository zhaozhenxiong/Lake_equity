# 版本记录

## 0.3.0 维护精简 — 2026-10-27

- 按静态/动态导入、资源和兼容入口闭包审阅冻结依赖，将 339 个 KHQuant 旧测试、技能和历史文档文件以及 501 个 CNEquity 测试、文档文件外部归档，共 840 个文件、22,426,880 字节；原始来源清单不改写，精确 omissions 记录原 SHA-256，未声明缺失仍校验失败。
- 将两份一次性迁移脚本和原始迁移 ZIP 外部归档；去除专项验收脚本中的本机绝对路径。生产依赖锁由 99 项收敛为 95 项，pytest 及其两项专属依赖移入开发锁，Qlib 环境继续独立。
- 公开发布包由基线 2,989 个文件收敛为 2,190 个文件。新增开发锁和 omissions 清单，保留运行资源、公开 API、模型与数据语义以及 `khquant` 兼容入口。
- 发行产物按正式发布身份保留当前 v0.2.0 和已验证 v0.1.0 回滚；清理五个无发布证据的中间导出、一个精确重复下载和保留 ZIP 中已全文核对的解包重复文件。实际回收分配空间 1,547,766,416 字节；Git 历史、发布报告、许可/研究/变更证据、Qlib 环境及业务数据未作为候选。
- 最终源码回归 920 项通过、1 项既有本地证据集成检查跳过；本地与 Qlib 合成学习冒烟、只读 HTTP 及 23 项桌面/移动浏览器检查通过。流水线只读预检仍与基线一样因开发机既有数据覆盖问题阻断，本轮未修改业务数据来制造通过结果。

本阶段只报告实测文件和空间变化；同盘外部归档不计为整盘空间释放。最终 ZIP 以随附 `SHA256SUMS.txt` 为准；安装验证范围和限制见 [发行说明](RELEASE.md)。

## 0.2.0 — 2026-10-25

- 加入一键研究流水线、覆盖判定与单一默认策略入口，并保留高级训练与历史研究功能。
- 加入模型归档、回测预检、失败构建清理及前瞻账本展示；运行中的构建受到清理保护。
- 加入因子与 Kronos 融合研究、手工账户快照和成交回填，以及从已保存回测构建次日条件计划。
- 增强 Sharpe、PSR/DSR 与绩效不可用原因的展示，整理任务、扫描及回测交互。
- 纳入研究价格来源相关修正；冻结研究依赖的本地补丁使用独立声明保存原始与当前 SHA-256。
- README 加入四张现有界面截图，公开流水线与研究说明；保留开发机原始历史文档，发行包使用公开版本。
- 完善白名单打包、来源核验与回归测试；源码 ZIP 提供文件清单和 SHA256SUMS。

本版不分发本机行情、账户、训练权重、私有研究记录或环境配置。安装验证范围及限制见 [发行说明](RELEASE.md)。
