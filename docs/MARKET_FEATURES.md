# 行情特征

统一导航顺序：数据湖 → 行情特征 → 结构与量价。入口为 `/#market`，采用 LakeEquity 原生页面，不嵌入旧控制台。

## 页面与来源

- 板块成交：成交额矩形树图、行业/概念/混合类型、成交额/增减/相对额/活跃度排序、完整筛选人口的增减各 Top5、20/60 交易日走势、固定成员分页及结构分析链接。
- 指数与广度：已发布市场广度；没有指数行情发布代次时明确显示不可用。
- 资金与估值：完整最新横截面的 PE TTM/PB 分布、缺失与非正值数量；各来源资金流、融资融券及北向历史分别展示。
- CNEquity 专项：申万行业的层级/权重分组、商品/期货/期权/Greeks、各宏观指标最近观测、现有关注池分钟覆盖。

直接复用 CNEquity 配置、登记表、单位合同、发布回执与 Parquet 查询原语。质量、来源健康、运行、调度和存储仍由数据湖及原生专项控制台负责。财报事件研究、IV 曲面和跨品种策略不是本次新增功能。

## 两种板块口径

默认成员聚合使用 CNEquity `sector_members` 和 `daily_bars`。仅纳入 CNEquity 沪深 A 股代码白名单，排除 CDR、指数、B 股、ETF 和北京市场。成交额为 CNY，页面换算亿元。分类只接受同一成员快照、同一采集 run、精确代码及成员一致且 SHA 核验通过的原档证据；无法确认时保留混合/未细分，不按名称猜测分类。

THS 来源板块使用 `sector_bars`，成交额为 `source_native`。没有经核实的换算关系时只能显示原始单位，不能标亿元。THS、东方财富和申万代码体系不按名称拼接；THS 成员映射和市场份额保持不支持。

## 计算边界

- 每项成员指标至少 5 个有效成员，且有效率达到该板块计算范围的 80%；不足保持空值。
- 成交额增减只比较前后两日共同有效的成员；绝不把成交额增减叫资金净流入。
- 相对成交额为当天成交额除以前 20 个交易日均额，不包含当天；窗口缺值不补零、不跨缺口挤成连续窗口。
- 多日板块收益是成员日等权观察收益的复合值，使用原始未复权价格，不是官方指数或可执行账户收益。
- 活跃度由相对成交额和绝对日涨跌幅的平均秩百分位组成，分类内排名；大跌也可能活跃，不代表强势或投资建议。
- 12 项板块观察特征包括四期收益、上涨比例、MA20 上方比例、20 日突破比例、成交额、市场份额、相对额、年化波动及回撤；不是股票 20 维 MLP 输入。
- 市场分母独立来自本地有效沪深 A 股行情，不叠加板块成交额；来源成员可能重叠、跨层级，不能相加当作全市场。

所有视图为当前固定成员历史回看，`training_eligible=false`、`pit_eligible=false`。捕获的是逐表发布版本集合，不宣称跨表原子 PIT。北向历史截止、缺少的资金流、指数和分钟数据维持真实状态；有行数不代表历史完整。

## 固定版本与 API

显式 `POST /api/v1/market/prepare` 才读取当前发布代次并计算，参数仅 `basis` 和可选 ISO 日期 `end`；不启动采集、全市场扫描、训练或旧研究计算。

`var/market_views/reads/` 保存内容寻址的来源清单，`views/<view_id>/` 保存视图和各板块细节。算法源码身份、来源版本、成员证据、政策和内容摘要参与身份绑定。GET 使用指定 `view_id`，不自动切换 latest；源代次缺失时拒绝恢复，不拿新数据冒充旧版本。

只读入口为 `/status`、`/features`、`/boards/{board_id}/history`、`/boards/{board_id}/members`、`/specialties`，统一前缀 `/api/v1/market`。走势图窗口仅允许 20 或 60，分页限 100；专项先基于完整总体计算摘要，再明确截断明细预览。

## 无干扰预览与上线

切换服务前，应确认已有任务结束或响应取消，且主服务没有其他活动任务。隔离预览启动方式：

```powershell
.\.venv\Scripts\python.exe scripts/preview_market.py --port 8131
```

打开 `http://127.0.0.1:8131/#market`。该脚本只创建行情路由和静态页面；其他 API 仅转发 GET 到固定 8130，POST 不代理。不会初始化主 JobManager，不协调/中断原任务，也不物化研究输入。行情视图计算仅写入独立 `var/market_views/`。

上线前重新只读核对 8130 的所有任务均无 queued/running/cancelling，并确认服务进程归属本项目；只重启该主服务，不触碰补采队列。扫描尚未停止或服务身份不确定时不强制切换。新进程使用项目既有 `lake.bat serve` / `python -m lake_equity.cli serve` 入口和 server.lock；禁止在同一工作目录启动第二个完整应用。

合成测试覆盖聚合数学、代码范围、来源分类、版本篡改拒绝、空态、请求约束、隔离预览与前端生命周期。本机运行数据和开发期浏览器验收记录不随源码发行；新安装需使用自己的数据核对覆盖和页面状态。
